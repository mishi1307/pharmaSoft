# Checklist de la demostración

## Antes de grabar o ensayar

- [ ] Oracle está disponible y tiene los datos de demostración.
- [ ] Redis está disponible.
- [ ] Backend inicia con el perfil y las variables de entorno esperados.
- [ ] Frontend compilado o `ng serve` responde en el puerto configurado.
- [ ] Usuarios de admin, vendedor y almacenero, y sus contraseñas, se verificaron localmente; no escribir contraseñas en este documento.
- [ ] Cliente y producto para la venta existen y el producto tiene stock suficiente.
- [ ] Los datos de volumen necesarios para mostrar la paginación están cargados.
- [ ] Se cerraron sesiones previas y se prepararon las pestañas de la demo.
- [ ] `/actuator/health` responde y se verificaron los permisos de métricas.
- [ ] La suite E2E tiene un resultado reciente con el commit correspondiente.
- [ ] Se eligió una venta identificable para relacionar comprobante, base de datos, auditoría y log.
- [ ] Hay video o capturas de respaldo disponibles si la conexión falla.
